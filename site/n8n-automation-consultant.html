n8n automation consultant.

I design and run n8n workflows that hold up in production: retries, alerts and documentation included.

Why n8n

Flexible, and easy to get wrong.

n8n handles integrations that simpler tools cannot, and it can be self-hosted. It also makes it easy to build a workflow that works in a demo and fails quietly in production.

I build for the second week, not the first demo: what happens if a step runs twice, which system wins when two disagree, and who is told when something fails.

What I do

Build, rescue and monitor.

New workflows for CRM, accounting, lead handling and reporting. Rescue work on estates that have grown messy, including error handling, naming, documentation and monitoring. I have built and operated an estate of more than twenty workflows for a marketing operations team.

Every build comes with documentation and a recorded walkthrough, and you own the instance and the code.
